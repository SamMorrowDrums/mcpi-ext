# pi-mcp-agent

MCP focused pi agent — building custom [MCP](https://modelcontextprotocol.io/) support as [pi](https://pi.dev/) extensions.

## Quick Start

```sh
curl https://mise.run | sh                       # install mise
eval "$(~/.local/bin/mise activate bash)"         # activate
mise install                                      # install node + aube
aube install                                      # install dependencies
mise run build                                    # build
mise run test                                     # test
```

See [AGENTS.md](AGENTS.md) for full tooling docs.
